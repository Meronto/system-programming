# System progs / Embedded / ASM / C — учебный репозиторий

> Вдохновлен этим [репозиторием](https://github.com/hira0mi/job-preparation)

Мой личный учебный репозиторий для систематического изучения
System Programming, Embedded и ASM и C.

Здесь я собираю конспекты, решённые задачи, эксперименты и небольшие
проекты, чтобы отслеживать свой прогресс, закреплять материал и
готовиться к техническим собеседованиям и соревнованиям.

> Репозиторий ведётся в первую очередь для обучения, поэтому здесь
> могут встречаться незавершённые решения, ошибки и неидеальный код.s

## 📚 Содержание

### ⚙️ Embedded
- `stm32/` — изучение stm32
- `esp32/` — изучение esp32
- `linux/` — изучение embedded-linux


### 🖥️ OSDev
- `boot_modes/` — загрузка железа и переключение режимов
- `kernel_core/` — память, прерывания и планировщик задач
- `drivers/` — драйвера и перифирия


### 📝 Notes
- `notes/` — конспекты и дополнительные материалы

### 💼 Interview
- `interview/osdev/` — вопросы и задачи для osdev-собеседований
- `interview/embedded/` — вопросы и задачи для embedded-собеседований


## 🎯 Цели

- научиться самостоятельно писать System-код без постоянной зависимости
  от LLM;
- систематизировать знания по классическому System progs и Embedded;
- укрепить ASM,C;
- изучить суть операционных ситем и микроконтроллеров;
- подготовиться к OSDev/Embedded техническим собеседованиям;
- участвовать в OSDev/Embedded -соревнованиях;
- постепенно собрать полноценное портфолио проектов.
